## What this kit is

A one-off founder-event mould: a live or asynchronous webinar-style event run by
Sally, timed to a natural community moment (for example a Camp Snooze cohort
milestone). Its job is to sell the annual plan honestly, in the window where trust
is highest, using the existing annual variant. No new offer, variant, or price is
created.
