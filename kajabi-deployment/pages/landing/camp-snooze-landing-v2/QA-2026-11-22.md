## Why the page moved from /camp-snooze-coaching

The `website-v1.6.50` deploy to /camp-snooze-coaching rendered without its video, fit check or pricing. Cause: that page's Nova theme (v0.2.7, theme 2168014017) outputs Custom CSS but prints the Custom JS field as literal text, `<script>{ { settings.custom_js; } }</script>`. The field only appears when it is non-empty, which is why the November 9 build, with JS inline in the block, worked. The folder location and the repo-root paste copy did not cause it. Kade duplicated the old Camp booking page (Encore Page theme, which outputs both fields) as /camp-snooze-program. See `docs/technical/KAJABI-SURFACE-CODE-SETUP.md`, landing pages.
