# index.html notes (pricing section and local call times)

Date: November 22, 2026. Source: `apps/snooze-website/src/camp-vsl/index.html` plus `src/camp-vsl/pricing/pricing.js`, compiled by `src/camp-vsl/build.py` into three paste targets (Kade ruling, November 22, 2026: landing pages keep code in the theme's own Custom CSS and Custom JS fields, no inline style or script in the HTML). The deployed files carry no comments; reasoning lives here.

## Paste targets

- `camp-snooze-coaching.css`: theme Custom CSS field. All rules (System Initialization tokens, base, buttons, page styles, pricing styles). No style tags.
- `camp-snooze-coaching.js`: theme Custom JS field. Fit check, captions Blob init (campReady guard kept), and pricing.js, in one IIFE. Runs once whether Kajabi loads it before or after the markup: it waits for DOMContentLoaded (or runs at once if the document has loaded), then looks for `#camp-vsl-page`; if the root is still absent a MutationObserver waits for it. pricing.js also has its own `data-pricing-ready` guard.
- `index.html`: markup only for the single code block (font link tags, page, inline footer). Zero style and zero script tags.
- `theme-payload.json`: `custom_css` and `custom_js` carry the file contents; the code block carries the markup. Regenerated by build.py, never edited by hand.
- The old source comments (System Initialization and Page-specific styles labels, two fit-check script comments) were removed from `src/camp-vsl/index.html` so the CSS and JS files pass the comment check. Meaning: CSS starts with the System Initialization block (tokens, base typography, `.snooze-container`, `.btn`, hero and step components, full-bleed fixes) and the page-specific rules follow it.

## New: call time display (pricing.js)

- `melbourneCallStart(YYYY-MM-DD)`: 10:00 in Australia/Melbourne as a real instant (offset resolved with Intl, so AEDT UTC+11 and AEST UTC+10 are both right, including the 5 April and 4 October 2026 changes).
- Cohort card: "First roll call" uses the cohort `start_date` (old page: first roll call is Monday morning of week one). FAQ and daily block use the next upcoming 10:00 Melbourne call and show no weekdays, with "the day before / the next day" for the visitor.
- Visitor on Melbourne, or any zone with the same UTC offset on that date and the same calendar day (Sydney, Hobart, Canberra): Melbourne only. Brisbane in summer is shown separately.
- Zone short name: tries en-AU, en-US, en-GB and takes the first that is not a bare `GMT+n`; falls back to `GMT+n`.
- Overnight: local start 22:00 inclusive to 06:00 exclusive. 06:00 exactly is not overnight; 22:00 is.
- Any Intl or timezone failure: "10-11am Melbourne time" only.
- Kick-off group call time is not shown (no data source for its time).
