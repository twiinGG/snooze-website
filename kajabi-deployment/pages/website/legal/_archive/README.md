## Deleted from Kajabi, 30 August 2026

Both URLs now return **HTTP 404**, by decision. Kade's ruling was remove, not redirect.

- `/3-4-month-baby-sleep-course-terms-and-conditions` (landing page `2150314925`)
- `/snooze-social-terms-and-conditions` (landing page `2150274555`)

Checked before deletion: neither had attached forms, neither was any offer's post-purchase page, and nothing in the deployed website code linked to either. Checked after: no live page links to them and the sitemap does not list them.

**One cost worth knowing.** The Snooze Social page carried a little organic search traffic. The 1 August 2026 GSC pull recorded **3 clicks, 70 impressions, average position 5.3**. That is now a 404. A redirect to `/terms-conditions` would have preserved it; the decision was to remove.

These files are kept only as a record of what the pages said. Do not republish them.
