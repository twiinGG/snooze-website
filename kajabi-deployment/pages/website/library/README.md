## 🎓 Learning Path Structure

The library page follows a three-tiered learning path:

1. **Tier 1: Foundational** (Section 3)
   - The Snooze Method foundational course
   - Entry point for all new members
   - Teaches core philosophy and mindset

2. **Tier 2: Age-Based Modules** (Section 4)
   - Comprehensive, stage-specific guidance
   - Complete after foundational course
   - Organized by baby's age/stage

3. **Tier 3: Sleep Troubleshooting** (Section 5)
   - Quick-reference support for specific challenges
   - For parents who've completed foundational learning
   - Issue-based guides (early rising, regressions, etc.)

## 📐 Design Principles

- **Three-Tiered Learning Path:** Foundational → Age-Based → Troubleshooting
- **Age-First Organization:** Matches how parents think
- **Direct Access:** Everything clickable from one page
- **Self-Serve Focus:** Supports 70% self-serve goal
- **Scalable Structure:** Easy to add more resources
- **Strategic Alignment:** Matches learning design framework
- **Accessible Language:** Straightforward, non-jargony, international English-friendly
