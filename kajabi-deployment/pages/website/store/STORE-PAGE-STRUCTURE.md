## Color Coding

- **Coral borders** = Featured cards (Membership, Camp Snooze)
- **Cream backgrounds** = Courses section, Camp Snooze section
- **White backgrounds** = Membership, Consultations, Products
- **Navy backgrounds** = Trust bar
- **Coral accents** = Badges, CTAs, icons

## Responsive Behavior

**Desktop (1024px+):**
- Hero: 2 columns (text | image)
- Courses: 2 columns grid
- Consultations: 3 columns grid

**Tablet (768px):**
- Hero: Stacked (text → image)
- Courses: 2 columns grid
- Consultations: 2-3 columns grid

**Mobile (320px-767px):**
- Hero: Stacked (text → image)
- Courses: 1 column stack
- Consultations: 1 column stack
- Featured cards: Full width, reduced padding

## Interaction Points

1. **Hero CTA** → Scroll to #membership
2. **Join Snooze buttons** → Checkout page
3. **Course cards** → Individual course landing pages
4. **Consultation cards** → Consultations page
5. **Camp Snooze** → Camp landing page (when available)
6. **Recommended Products** → Products page

## Animation Timing

- **Hero content**: 0s (immediate)
- **Hero image**: 0.2s delay
- **Featured cards**: 0s (immediate)
- **Course cards**: 0.1s, 0.2s, 0.3s, 0.4s delays
- **Consultation cards**: 0.1s, 0.2s, 0.3s delays

All animations: `fadeInUp` 0.6-0.8s duration, ease-out timing
