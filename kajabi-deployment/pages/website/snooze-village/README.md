# Snooze Village visual showcase

Deploy `snooze-village-page.html` to a full-width, flush Custom Code section on a Kajabi Website Page at `/snooze-village`.

The page is a public visual tour of the resources included with the Snooze Membership. It does not expose member-only content. The shared Website theme supplies navigation and the scoped styles in `global/css/theme-custom-code.css`.

Use the page settings in `page-metadata.md`. The wrapper is `#snooze-village-page`.
