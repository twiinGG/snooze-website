## Quick Access Tips

### In Kajabi (Copy-Paste Workflow):
1. **For HTML Content:**
   - Open lesson/page in Kajabi
   - Switch to "Source Code" or "HTML" view
   - Click **Raw** link above (opens in new tab)
   - Select all content (Cmd+A / Ctrl+A)
   - Copy (Cmd+C / Ctrl+C)
   - Switch back to Kajabi tab
   - Paste (Cmd+V / Ctrl+V)
   - Save

2. **For Email Content:**
   - Open email in campaign
   - Switch to HTML/Source view
   - Click **Raw** link above
   - Copy all content
   - Paste into email editor
   - Save

3. **For Product Settings:**
   - Open product Settings → Details
   - Click **Raw** link for metadata file
   - Copy title and description separately
   - Paste into respective fields in Kajabi
   - Save

### Always Up-to-Date:
- These links point to the `main` branch
- Files are always current (no need to download/update)
- Changes in repo automatically reflected in links
- **No GitHub account needed** - public repository

### Important:
- **Kajabi cannot embed GitHub links directly** - you must copy-paste the content
- Raw links show plain text/HTML (perfect for copying)
- View links show formatted GitHub UI (for reference only)
