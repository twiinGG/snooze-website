# VA Trial: Lead Magnet Funnel Deployment

**Role:** Kajabi Funnel Implementer  
**Trial Duration:** 1 bundle deployment  
**Success Criteria:** Clean execution, accurate wiring, clear documentation

---

## What You're Being Tested On

This trial is designed to test:

1. **Execution accuracy** - Can you follow a system without improvising?
2. **Judgment** - Do you flag issues early and propose fixes?
3. **Independence** - Can you work without constant clarification?
4. **Systems thinking** - Do you build reusable patterns, not one-offs?
5. **Documentation** - Do you document while doing, not after?

**You are NOT being tested on:**
- Speed alone
- "Knowing Kajabi" (we'll teach you)
- Enthusiasm
- Creativity or strategy (that's provided)

---

## The Trial Task

**Deploy one complete lead magnet funnel** using the provided SOP and content bundle.

**Bundle:** `LMCR08` - 3-4 Month 4hr Feeds Free Module

**Time:** 45-60 minutes (quality over speed)

**Deliverables:**
1. Fully functional funnel in Kajabi
2. QA test results (checklist completed)
3. Documented URLs (offer, thank you page, product)
4. Brief notes on any issues encountered and how you resolved them

---

## What Success Looks Like

### Front End
- [ ] Opt-in page deployed correctly
- [ ] Form behavior works
- [ ] Thank-you page displays properly
- [ ] Mobile experience is clean

### Inside Kajabi
- [ ] Course cloned and configured correctly
- [ ] Orientation lesson replaced
- [ ] Target module unlocked
- [ ] Paywall added after unlocked module
- [ ] Wrap-up lesson created with CTAs at end of unlocked module
- [ ] Paywall triggers on locked content

### Automations
- [ ] Ghost offer created and hidden
- [ ] Automation triggers on offer purchase
- [ ] Day 0 post-purchase email sent immediately
- [ ] Tag applied correctly
- [ ] Email campaign subscription works
- [ ] 3-email nurture sequence uploaded (Day 2, 4, 6) with correct timing
- [ ] Exit rules configured (stops if they purchase)

### QA
- [ ] End-to-end test completed
- [ ] All checklist items verified
- [ ] Mobile tested
- [ ] Email received and formatted correctly

### Documentation
- [ ] URLs documented
- [ ] Any issues flagged with proposed solutions
- [ ] Naming conventions followed

---

## How to Approach This

1. **Read the SOP first** - Understand the full process before starting
2. **Gather all resources** - Confirm you have everything from the "What You'll Receive" section
3. **Follow the system** - Don't improvise. If something doesn't work, flag it and propose a fix
4. **Document as you go** - Don't wait until the end
5. **Test thoroughly** - Complete the QA checklist, don't skip steps
6. **Flag issues early** - If something is unclear or broken, say so immediately

---

## Red Flags (What Gets You Filtered Out)

- **Needing constant clarification** - We're testing if you can work independently
- **"Kind of" understanding funnels** - You need to understand the system, not wing it
- **Blurring strategy and execution** - Strategy is provided. Your job is deployment.
- **Building one-off solutions** - This needs to be replicable 11 more times
- **Skipping documentation** - Documentation is part of the work, not extra
- **Not testing thoroughly** - Broken automations are urgent. Test everything.
