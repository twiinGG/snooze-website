## 📝 Documentation Standards

### When to Create New Docs
- **Permanent Reference:** Technical specs, guides, strategies
- **Major Changes:** Document in CHANGELOG.md, not separate file
- **Client Review:** Create review documents as needed

### When NOT to Create New Docs
- ❌ Session summaries (use scratchpad instead)
- ❌ Execution summaries (update CHANGELOG.md)
- ❌ Cleanup summaries (update CHANGELOG.md)
- ❌ Temporary notes (use scratchpad)

### Archiving Policy
- Keep only active, useful documentation
- Archive historical/outdated docs to `archive/`
- Consolidate related docs when possible
- Remove unnecessary summary files
