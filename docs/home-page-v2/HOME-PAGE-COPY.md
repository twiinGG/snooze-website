## Notes for Review

### Tone of Voice Checklist
- [ ] Uses "I would" / "I like to" / "For me" language
- [ ] Uses "You can" / "You don't have to" (permission-giving)
- [ ] Uses "Usually" / "Often" (not "always/never")
- [ ] Avoids em dashes (—) — use colons, commas, periods instead
- [ ] Avoids contrast statements ("not X, it's Y")
- [ ] Avoids "You should" / "You must"
- [ ] Evidence-based, supportive, practical, confident, judgment-free, human

### Key Differentiator Points (from Sally call)
- Apps give generalised advice that doesn't work for non-average families
- Apps/courses lack accountability — no one checking in
- Snooze is like a personal trainer vs Nike app
- Accountability: "Have you moved to 4 hourly feeds yet? If not, why?"
- Snooze is for people who've tried apps/courses and they didn't work
- The continuum: winging it → apps/courses → consultant → Snooze (middle ground)
