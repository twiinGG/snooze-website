## Page Types in Kajabi

### System Pages
- **Metadata:** Controlled by system settings (shared across all system pages)
- **Examples:** Login, 404, Thank You, Store, Contact, Announcements
- **SEO:** Cannot set individual SEO per system page
- **Status:** Always "System" status

### Custom Pages
- **Metadata:** Individual SEO settings per page
- **Examples:** Home, About, Blog posts, Landing pages
- **SEO:** Full control over title, description, social image
- **Status:** "Published" or "Draft"
