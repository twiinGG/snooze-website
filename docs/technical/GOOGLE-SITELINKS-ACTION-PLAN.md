---

## Current Situation

### Problem
- Google search results show "Our store" as a sitelink under the main search result for "The Sleep Concierge"
- Store page URL: `joinsnooze.com/store`
- **Constraint:** This is a Kajabi system page (cannot be unpublished or removed)
- **Constraint:** Kajabi does not support 301 redirects
- We need to control what pages Google shows as sitelinks

### Key Constraints
1. **System Page:** The store page is a Kajabi system page - cannot be deleted or unpublished
2. **No Redirects:** Kajabi does not support 301 redirects for system pages
3. **Already Indexed:** Google is already showing it as a sitelink
4. **Limited Control:** System pages have limited customization options

### Google Sitelinks Overview
Sitelinks are automatically generated by Google based on:
- Site structure and navigation
- Internal linking patterns
- Page importance and relevance
- User behavior data

**You cannot directly control which sitelinks appear**, but you can influence them through:
1. Site structure and navigation
2. Internal linking
3. Removing/updating outdated pages
4. Using structured data (SiteNavigationElement schema)

### Phase 3: Control Sitelinks (Long-term Strategy)

#### Step 3.1: Optimize Site Structure
Google prioritizes sitelinks based on site structure:

- [ ] **Ensure Clear Navigation Hierarchy**
  - Main pages should be in primary navigation
  - Secondary pages in footer or secondary nav
  - Important pages should be linked from homepage

- [ ] **Review Current Navigation Structure**
  - Homepage (`/`)
  - Main landing page (`/snooze`)
  - Key product pages (age-specific help pages)
  - About page (`/about-sally`)
  - Blog (`/blog`)
  - Recommended Products (`/recommended-products`)

#### Step 3.2: Internal Linking Strategy
- [ ] **Link Important Pages from Homepage**
  - Ensure key pages are linked from homepage
  - Use descriptive anchor text
  - Include in main navigation

- [ ] **Strategic Internal Linking**
  - Link to important pages from multiple high-traffic pages
  - Use consistent anchor text
  - Avoid over-linking (keep it natural)

#### Step 3.3: Add Structured Data (Optional but Recommended)
- [ ] **Add SiteNavigationElement Schema**
  - Add JSON-LD structured data for main navigation
  - Helps Google understand site structure
  - Can influence which pages appear as sitelinks

**Example Schema:**
```json
{
  "@context": "https://schema.org",
  "@type": "SiteNavigationElement",
  "name": "Main Navigation",
  "url": "https://joinsnooze.com/",
  "hasPart": [
    {
      "@type": "SiteNavigationElement",
      "name": "The Snooze Method",
      "url": "https://joinsnooze.com/snooze-method"
    },
    {
      "@type": "SiteNavigationElement",
      "name": "About Sally",
      "url": "https://joinsnooze.com/about-sally"
    }
  ]
}
```

**Time Estimate:** 2-3 hours
